# 灵枢实验室 · 赛博格标本馆（90s CRT / Y2K 线束拼贴）

系列第四种风格，参考方向：老式 CRT 显示器堆叠、螺旋虹膜之眼、插电的大脑、
Johnny Mnemonic 式终端 —— 赛博格拼贴 + Y2K 电线贴纸美学。

## 元素对照

| 参考图 | 站内转译 |
|---|---|
| Compaq 显示器堆叠（人体碎片） | Hero 四设备拼贴：**台式电脑 / 手机 / 笔记本 / 智能手表**，全部 CSS 手绘、屏幕实时 Canvas 动画 |
| 螺旋虹膜之眼 | 台式机大屏：Canvas 阿基米德螺旋 + 瞳孔呼吸 + 高光，缓慢旋转 |
| 彩色电线 + emoji 贴纸 | 线束分隔 SVG（红/蓝/黄/绿/黑五色贝塞尔）+ 白边 emoji 贴纸 |

### 四设备屏显内容

| 设备 | 造型细节 | 屏内动画 |
|---|---|---|
| 台式电脑 | CRT 塑料壳 + 梯形颈 + 底座 + 电源 LED | 多人超扫描（真像素屏）：96×72 离屏渲染 + 无平滑放大，像素小人围桌、头顶量化脑波柱、脑间琥珀脉冲点阵沿弧线往返 |
| 手机 | 刘海 + 侧键 + 竖屏 9:18 | 情绪解码：颜文字 (T_T)/(^_^)/(⊙o⊙)… 周期切换，乱码解码过渡 + 置信度 |
| 笔记本 | 屏盖 + 键盘阵列 + 触控板 + 电源 LED | 竖臂腕上高密度电极贴片（5×7=35 通道、每电极内 3×3 触点阵；精巧平行走线引至右缘焊盘条汇成单缆引出）+ 右侧三路实时测量曲线 |
| 智能手表 | 上下表带 + 圆角方表盘 | BPM 数值（70±随机）+ 琥珀色心电尖波 |

## 其余细节

- 标本目录：粗野主义行列表 + CSS repeating-gradient 条码 + READ → 箭头
- 硬件规格表：塑料面板 + 四角螺丝 + 硬阴影（8px 偏移黑影贯穿全站）
- 标题高亮：`<mark>` 色块 + 硬阴影（红/黄交替）
- 大标题「把意识，接入机器。」——意识一词红块反白
- 页脚：巨型条码 + "PROUDLY OPERATED BY HUMANS*"
- 零第三方依赖（纯 Canvas 2D + DOM），rAF 看门狗，`prefers-reduced-motion` 降级
