# 张致同课题组 · Zhitong Group

北京中关村学院张致同研究员课题组官网。课题组围绕脑机接口（BCI）与神经精神疾病辅助诊断开展研究，承担 NeuroDiagAI 项目，研究方向涵盖：脑机接口系统、先进神经电子界面、可穿戴传感、脑电解码与脑机大模型、EEG 辅助诊疗、类脑智能、眼电交互。

**网址**：<https://www.zhitong-group.com>

- **首页** — 课题组定位与入口
- **课题组** — NeuroDiagAI 项目背景
- **PI** — 张致同研究员简介、荣誉与精选论文
- **成员** — 博士成员卡片与人员课题图谱
- **研究** — 七个研究方向简介
- **成果** — 代表性成果列表
- **加入我们** — 招生与联系
